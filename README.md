# Consumindo API com ESP32

Projeto que fiz pra aprender a fazer o ESP32 puxar dados de uma API.

Usei PlatformIO pra organizar tudo. O projeto ficou dividido assim:

- incluir / biblioteca - onde ficam as libs
- src - código principal do ESP32
- teste - testes
- arquivo.txt - anotações
- platformio.ini - configuração da placa

A ideia é o ESP32 conectar no WiFi e fazer requisição HTTP pra trazer os dados em JSON.

Fiz no SENAI pra parte de IoT, ainda tô melhorando a conexão.
